## 对照与实际修改

参考本机 DeepSeek Harness `687f282e8625c6b8d11ff58211a90524be2e4317` 中的 [TrajectoryTable.module.css](https://github.com/deepseek-ai/deepseek-harness/blob/687f282e8625c6b8d11ff58211a90524be2e4317/packages/client/ui-trajectory/src/client/TrajectoryTable.module.css) 和对应 `TrajectoryTable.tsx`，采用实际网页事件表，而非旧版 standalone Cell。

| 原界面 | 当前界面 |
|---|---|
| 大标题、导读、每轮业务标题、模型/工具小标题、上下文写回解说 | 36px 工具栏，事件直接入表，不重复解释 Agent Loop |
| 每轮展开一段长文，五次工具分散在多屏 | 30px 行高，10 条用户/模型/工具记录桌面首屏可见 |
| 工具用途、路径、概括、技术名多行堆叠 | 一行“工具名 + 参数目标 → 返回内容”，超长截断，点选查看完整内容 |
| 独立段落解释错误会交给模型 | 保留红色错误行，下一条模型响应直接呈现处理过程 |
| 半屏被动详情；窄窗口整页替换 | 点选记录后打开局部检查器；窄窗口从右侧覆盖，关闭回到同一行 |
| 多次出现“结构化记录 / 字段 / 原文”工具栏 | 详情中直接显示字段树；顶层概览/输入/输出/原文各司其职 |

默认记录仍为同一脱敏样例：用户请求、4 次模型响应、5 次工具调用。模型调用边界以点和 #1—#4 表示；工具隶属对应响应，可单独折叠或统一折叠。没有自拟的阶段名称或思考总结。

## 尺寸与状态

- 表格行 30px，12px 正文，18px 行内代码；事件列 84px，窄表 64px。辅助文字 10/11px，边界编号 9px；检查器正文 13px、代码 12.5px。主要字重 400/500/600。
- 间距主要为 2/4/8/12/16px；轮次边界保留 9px 标记空间，不用大段留白分组。表格无卡片圆角；类型标记 2px，工具栏控件 3px。颜色只区分用户、模型、工具和失败，选中沿用 A 的绿色。
- 检查器宽 `clamp(320px, 38%, 440px)`，标题 42px、Tabs 34px；760px 以下覆盖右侧最多 92% 宽度。表与详情各自滚动。
- 工具栏提供搜索、折叠轮次/调用、切换检查点和时间概览。时间概览只画已知事件时间点，不补造耗时跨度、吞吐量或 token 指标。
- 键盘上下移动记录，Enter/Space 打开，Escape 关闭并恢复触发行焦点。完整参数、结构化输出、错误和原始字段在检查器中可读、可复制。
- 历史检查点没有最终模型回复。新请求只有已发出/中断记录，不套用初始任务的工具或成功状态。
