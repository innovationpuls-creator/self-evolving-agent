# 第三轮 · 会话书桌

本轮只精修 A 的独立 Demo。侧栏、中央工作区和按需详情保持；轨迹仍采用紧凑事件表。用户尚未进行本轮审美验收。

## 七模块对照

| 模块 | 修改前的问题 | 当前处理 |
|---|---|---|
| 会话 | 重复页头、报告前堆叠用户输入、所有请求复用报告 | 收紧标题与消息间距，输入随文本增长；消息顺序续接；顶部会话样例切换编程、研究与文件清单，使用同一 Markdown 渲染器 |
| 轨迹 | 公共正文排版可能破坏密度 | 保留30px事件行和检查器；有独立 transcript 的会话不会套用文档工具调用 |
| Memory | 正文像宣言，静态使用说明占主位置 | 16px当前认识，缩短目录节奏，按需显示对象特有提示；历史选择不污染当前来源；冲突就地比较草稿 |
| Reflection | 结论重复，不确定性整块抢占注意 | 先展示认识前后变化，再呈现事实与不确定性；无发现收短；关联入口保留 |
| Skill / Tool | 装饰图块与重复版本，参数结构提前暴露 | 名称旁显示版本，去掉装饰图块；说明与维护页签保留；完整Tool声明按需展开 |
| Evolution | 属性式论证重复，终态被时间线占满 | 删除A重复方向章节；开发终态日志默认收起；授权目标与范围在前，本机权限在批准前直接可读 |
| 模型 | 已有授权仍先强调登录，测试开关混入正文 | 调用检查提前；演示情境收拢，登录与退出仍可发现 |

## 视觉规则与组件

A 使用独立 round3 样式，未修改全局字号或B色彩。阅读正文16px/1.75，辅助13px，对象标题20px、模块标题24px。轨迹保持独立12px密度。文字、代码和表格降低普遍的绿色倾向，绿色保留选择与操作含义。Modal、Menu、Tooltip 的A Portal有明确作用域。

复用既有 Radix、Markdown/GFM、Highlight.js、Diff、JSON 树。未引入依赖、字体或品牌素材。按钮、页签、字段、对话框、复制、错误和空状态保留既有交互能力；本轮没有重写全部公共状态组件。

## 实际视觉批评与修正

1. 初版截图显示 Reflection 虽缩短页头，正文仍重述标题；修正导语并提前认识差异，使读者先看到结果。
2. Evolution 初版仍是三个等权章节；移除A重复方向章节，保留触发事实与不确定性。
3. 授权初版仍先出现权限长文再出现目标；权限移入目标与范围之后，批准之前。终态开发记录收起，进行中保持展开。
4. 模型初版仍把登录置于调用检查之前；将检查提前，模拟错误开关收为演示情境。
5. 390px截图显示顶栏新增样例导致词语折行；收紧演示工具栏，避免挤压实际模块内容。

初版证据在 evidence/round3/initial，修正后在 final；before保留此前六模块的桌面截图，轨迹的旧基线在 evidence/trace-ledger。完整索引见 evidence/round3/index.html。

## 操作与复现

运行 `npm run dev --prefix prototypes/d6`，打开 http://127.0.0.1:4176/?route=quiet。
顶部“会话样例”切换内容；自由输入只模拟消息续接，不调用模型，不伪造工作成果或工具记录。刷新恢复初始状态。

原回归：`D6_EVIDENCE_DIR=../evidence/round3/final/ npm run test:browser --prefix prototypes/d6`。
轨迹：`D6_EVIDENCE_DIR=../evidence/round3/trace/ npm run test:trace --prefix prototypes/d6`。
补充会话：`node prototypes/d6/scripts/round3.mjs`。

## 仍有的实际限制

- 自由输入是普通模拟回应，不是真实模型结果；新增样例覆盖不同内容，但研究样例仍比真实多小时研究简短。
- 公共空白、加载和错误页面继续复用第二轮 StateGate，尚未全部改为模块局部状态骨架。
- JSON沿用现有字段树与代码原文；会话中的JSON代码块仍以高亮代码展示。
- Memory新增来源区分用户输入，但原有历史案例仍是固定脱敏数据，没有模拟完整来源权限系统。
- Desktop原生窗口、真实OAuth及屏幕阅读器全流程不属于本次浏览器证据。

这些限制不以构建成功或自动化通过代替用户审美验收。正式界面与Host未改动。

## 组件与状态审查清单

| 组件 / 关系 | 本轮设计处理 | 检查证据 |
|---|---|---|
| 导航 / 对象目录 | 保留现有入口；收短目录行，不改当前对象定位 | final 两路线、五尺寸主页面 |
| Button / 图标操作 / Menu | 主操作保留实色；已有授权时登录降为次级；A菜单与提示独立作用域 | Settings、引用与搜索、states-results |
| Input / Textarea / Select | 会话输入自动增长至160px；授权目标与范围前置；输入法发送守卫保留 | browser-results、supplement、多轮与窄屏 |
| Tabs / 历史选择 | 当前知识与历史分开；桌面仅修订轨道，窄屏仅选择器 | Memory、memory-diff、修订不变性断言 |
| Dialog / Drawer / Tooltip | A Portal明确隔离；授权按决定顺序阅读；Escape与焦点返回 | grant-top/bottom-390、states-results、trace |
| Markdown / Table / Quote | 正文16px、分层标题、紧凑表格；不同任务共享渲染 | 会话报告、研究长文、编程样例 |
| Code / Diff / JSON | 保留高亮、复制、行号、折行、树与原文；Tool声明按需展开 | Diff检查、Tool未知结构、嵌套数据 |
| Empty / Loading / Error / Toast | 保留既有状态入口与恢复操作；本轮没有重写StateGate | final各模块空白、加载、失败；states-results |
| 运行 / 授权 / 终态 | 未授权不能开发；失败保留旧版；成功自动生效；终态结果先于过程 | contracts-results、开发成功/失败/取消截图 |

所有操作使用脱敏内存模拟。样例选择器替换当前演示会话内容，刷新恢复；它不是导入真实会话功能。补充样例的回复不产生不存在的Tool证据。
