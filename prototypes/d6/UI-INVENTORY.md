# D6 第二轮 · 界面与组件清单

本清单以当前正式产品的用户能力为边界。Demo 使用相同的脱敏案例，所有操作只更新内存。第一轮原件保留于 `round1/`；本轮截图与检查在 `evidence/round2/`。本清单中的设计判断由用户评审，自动化结果仅证明对应操作。

A 的轨迹后续按 Agent Loop 重组；当前组件、状态及视觉验证以 [轨迹修订](TRACE-LOOP.md) 为准，原截图保留对照。

## 主要界面

| 界面 / 对象 | 默认表达与主要任务 | 重要操作与状态 | A / B 的组织差异 | 源码 |
|---|---|---|---|---|
| 全局工作区 | 当前会话、项目位置、连接，轻量长期入口 | 全局搜索、模块切换、导航收起、待决定入口、离线反馈 | A 常驻会话；B 顶部目的层与对应目录 | `components/shell.tsx` |
| 会话目录 | 以工作目标命名，状态弱于标题 | 创建、切换、改名、归档、独立草稿、长标题 | A 最近会话；B 工作目录与工作结果 | `components/shell.tsx` |
| 新会话 | 名称与 Host 工作目录 | 取消、创建；固定模拟项目，不暗示上传本机文件 | 共用聚焦创建表面 | `components/shell.tsx` |
| 输入 | 目标文本为主，引用作为上下文 | 文件与 Skill 选择/移除、模型与推理、禁用发送、IME、Cmd/Ctrl+Enter | A 会话下方；B 报告与会话分别阅读，输入保持在工作区 | `pages/Conversation.tsx` |
| 消息与结果 | 用户请求、Agent 结论和覆盖边界 | Markdown、表格、代码、长文、运行中、停止、中断、准备新请求 | A 按会话阅读顺序；B 报告优先＋关联侧栏 | 同上 |
| 会话历史 | 当前分支与只读旧分支分开 | 查看旧记录、明确切换执行位置、压缩上下文 | 共用语义，入口保留当前工作 | 同上 |
| 轨迹 / Turn | 一次工作内的模型轮次和调用 | 选择调用、上下文、未知指标、停止、历史检查点不完整 | A 纵向执行叙事＋右侧详情；B 调用登记表＋下方记录阅读 | `pages/Trace.tsx` |
| Tool 调用 | 目的→目标→状态→业务结果 | 失败原因、下一步、参数、完整输出、未知 Extension 回退 | 共用内容规范，工作区结构不同 | 同上 |
| JSON / 原始依据 | 语义摘要之后的结构阅读 | 对象/数组层级、字段类型、折叠、原文、复制、脱敏与完整性边界 | 共用基础渲染 | `components/content.tsx` |
| Memory 索引 | 当前认识、性质、范围、状态分开 | 搜索、全局/项目/历史筛选、补充、删除、调整范围 | A 知识索引＋阅读页；B 跨对象登记册＋选中认识 | `pages/Memory.tsx` |
| Memory 修订 | 当前认识与历史对比 | 选修订、逐行差异、完整内容、来源、编辑理由、冲突阻断和重新核对 | A 当前认识更突出；B 目录属性可横向比较 | 同上 |
| Reflection | 发现、直接依据、不确定性、后续影响 | 记录筛选、无发现、环境不可用、重新审查、关联记忆和建议 | A 回顾日志；B 按时间建立档案，观察/不确定性并列 | `pages/Reflection.tsx` |
| 建议 | 可论证的改善价值与不确定性 | 开始讨论、忽略、已处理、恢复待决定 | A 单项建议阅读；B 建议队列与活动工作区 | `pages/Evolution.tsx` |
| 讨论 | 先明确目标；此阶段没有开发工具权限 | 用户发送讨论内容、补充目标、审阅授权 | A 连续阅读；B 活动目录、讨论、背景并列 | 同上 |
| 开发授权 | 用户要作出的具体决定 | 具体目标、已有范围、新建名称、基础版本、本机权限、取消 | A 聚焦对话框；B 独立决策工作区 | 同上 |
| 自主开发 | 实际观察事件，不伪造百分比 | 开发中、检查中、成功、失败、取消、无代码成果、查看授权证据 | A 活动阅读流；B 阶段目录保留背景；阶段不可点击跳过 | 同上 |
| Skill 目录 | 用途优先，指引与扩展不混淆 | 搜索、选择、启停、禁用说明、在会话引用 | A 用途目录与说明并列；B 能力矩阵与选中能力阅读 | `pages/Skills.tsx` |
| Skill 文件 / 候选 | 正式内容与未生效修改分开 | 编辑、候选 Diff、精确内容审查、依赖检查、失败保留旧版 | 共用生命周期业务控件，不套通用卡片 | 同上 |
| Tool 目录 / 依赖 | 工具来源、所属能力与四种可用性事实 | 原生 / Extension、加载/声明/活动权限、Schema、依赖树 | 独立于 Skill 指引阅读，保留所属返回 | 同上 |
| 执行信任 / 版本 | 当前正式引用与不可变历史分开 | 审查勾选关口、检查、生效、恢复版本、回退范围确认 | 不把安装/保存/启用当作信任；D4 证明与人工审查区分 | 同上 |
| 模型授权 | 提供方、授权来源、调用检查分开 | OAuth 等待/取消/过期、模拟回调、Key 校验/保存、导入副本、退出 | A 按设置页签；B 环境目录与连接配置 | `pages/Settings.tsx` |
| 连接 / 恢复 | Host 位置与中断恢复边界 | 模拟断线/重连、读取失败、查看中断会话、原生维护说明 | 不添加远程 Web 备份恢复能力 | 同上 |

## 共用组件审查

| 组件 | 目的与视觉角色 | 状态 / 内容边界 | 输入与焦点 |
|---|---|---|---|
| Button / IconButton | 实心只给当前主要行动；描边操作，文本辅助 | Hover 只改变底色；disabled 清晰保留位置；loading 有文字 | 原生 button；可见 focus ring；图标有可访问名称和 Tooltip |
| Input / Textarea | 明确标签、提示和局部错误 | 空、长内容、特殊字符、只读、无效 Key、未保存候选 | 原生语义；Field 生成唯一标签关联；IME 不误发送 |
| Select | 小规模稳定选项，不自建复杂浮层 | 已选、禁用、长选项在控件内截断 | 原生选择器保留系统键盘行为 |
| Tabs | 同一对象的阅读角度，不替代全局导航 | 下划线标当前位置，不制造一排等权按钮 | Radix 方向键 / Home / End / Tab |
| Menu | 次要管理与 Demo 场景操作 | 文案说明动作，危险项用语义色 | Radix 管理方向键、Escape、焦点返回 |
| Dialog / Drawer | 需要暂时聚焦的决定或关联取证 | 标题、描述、独立滚动；窄屏满宽；危险范围持续可见 | Radix 阻止背景交互，Tab 包含，Escape，返回触发者 |
| List / Table | 列表适合用途浏览，表格适合跨对象比较 | 选中与 hover 不等权；长名称折行；窄屏进入单对象 | 可操作单元是 button，不让整行 div 冒充按钮 |
| Tree / Disclosure | 依赖、JSON、上下文等逐级深入 | 层级缩进、对象/数组数量、null/未知、完整原文 | 使用 button / 原生 details，不依赖鼠标悬浮 |
| Tooltip | 解释图标短义，不承担权限或错误内容 | 延迟出现，不能隐藏必要说明 | Radix 同时支持 focus 与 hover |
| Toast | 已完成的轻量回执 | 不承载唯一的失败、授权或生效事实 | role=status；关键结果保留在对象页面 |
| Markdown | 长结果阅读，不暴露渲染实现 | 标题、引用、链接、表格、任务列表、代码；禁 HTML | GFM；表格局部滚动；正文不跟随技术字段字号 |
| Code / Diff | 读源码、复制、定位和比较 | 语言、位置、行号、高亮、长行、折行；Diff 真实计算 | 复制有已复制反馈；完整内容仍可访问 |
| JSON Viewer | 未知结构也能检查，不硬扁平化 | 字段/原文切换、对象数组、嵌套、null、未知返回 | 每级展开按钮；原文可复制；颜色不独自承担类型 |
| Empty / Loading / Error | 解释当前为什么没有内容、下一步是什么 | 模块专属文案；读取失败不等于数据删除；加载不假造进度 | 重读/回已有内容/创建；不自动重发任务 |
| Confirmation | 能力回退、授权、退出等明确决策 | 影响对象、范围、保留项、主要按钮动词准确 | 不以 Toast 代替，取消可返回原处 |
| Status / Notice | 状态靠近对应对象，不制造指标卡 | 执行结束、结果未知、候选失败与已生效严格区分 | 状态有文字；运行有轻动效并尊重 reduced-motion |

## 没有虚构为现有能力的内容

- 产品没有“暂停后从任意 Tool 安全续跑”的承诺；Demo 用停止/中断/新请求表达，不添加暂停续跑按钮。
- 搜索、对比阅读、来源 Drawer、对象返回位置、信息分组是本轮交互提案；不声称正式 Host 已提供这些前端体验。
- 空/加载/失败/长内容由顶栏 Demo 场景控制；OAuth、检查与开发结果均为模拟。原生 Desktop 的外链、签名与真实 OAuth 回调不记作本轮验收。
