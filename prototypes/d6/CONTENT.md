# 内容呈现与状态语义

## 结果 → 结构 → 原文

三层不是强制三级弹窗，而是内容的阅读顺序。若工具缺少可靠业务摘要，直接说明“已收到返回值，业务结果未知”，进入通用结构视图。不能把未知数据包装成一句确定结论。

### Markdown

继续使用仓库已有 `react-markdown` 与 GFM。正文、标题、列表和引用按阅读关系排版；表格限定在自身横向滚动，避免整页宽度溢出。代码块另有工具栏。禁用原始 HTML，图片引用不主动请求外部资源；外链使用安全协议处理和 `noreferrer`。内部 CJK 正文与等宽技术内容分开，长文在阅读区滚动，输入保持可用。

### 代码

Highlight.js 按需注册 TypeScript/JavaScript、JSON 和 Markdown；未知语言回退纯文本。高亮引擎负责转义，原始字符串独立保留用于复制。显示语言或文件位置、行号、复制状态、局部横向滚动和折行选择。复制失败保留可选择的原文，不声称已复制。行号是定位辅助，不进入复制内容。

### Diff

默认保留变化附近三行上下文，较长未改片段可逐段展开；完整内容提供修改前与修改后各自的可复制原文。

使用 `diff` 的 `diffLines` 计算真实行差异，保留旧/新行号、新增/删除符号和没有变化的真实行。删除和新增同时使用符号、文字位置和颜色；完整内容可切换。废除第一轮固定“上下文保持不变”的文案，避免制造不存在的取证依据。

### JSON 与未知 Extension

字段视图保留原键、对象/数组、数量、null、字符串/数字/布尔类型与层级。每层展开由可聚焦按钮控制；原文视图包含完整 JSON，可复制。复杂记录不强行转成表格。未知 Extension 显示名称、来源、输入与返回，明确不能推断业务成功。

### Tool

默认阅读：执行目的→目标文件/对象→观察状态→返回了什么→有哪些限制。失败的调用说明原因与下一步，避免只有 `ENOENT`。参数、结构结果、原始错误和取证记录按需深入；调用返回、执行结束、任务成功不是同一状态。调用标识与指标放在技术详情边缘，未知耗时不填零。历史分支只读，上一检查点保持不完整标记。

### Memory

先展示当前认识和适用状态，再展示形成原因与来源。性质（事实/经验/决定/怀疑）和状态（当前/撤销/删除）分开。修订比较保留历史选项，用户修正必须附理由；编辑冲突阻止覆盖并保留草稿。项目来源撤销不抹去通用经验，也不因切回分支自动复活决定。调整范围时解释历史来源不会随当前范围扩大而披露。

### Reflection

结论标题稳定，不将整段 summary 加粗成标题。依次展示观察、依据、不确定性和后续变化；知识与建议分别链接。“无新发现”使用短记录，环境不可用说明没有运行，不制造空洞的分析报告。重新审查是用户明确的新请求，不代表后台已有开发权限。

### Evolution

建议论证、目标讨论、用户授权、Agent 开发、Host 检查、自动生效分别使用不同业务表面。讨论不自动发送。授权冻结具体目标、已有/新建 Skill 名称与基础版本；本机权限说明在决策表面直接可读。阶段记录不能点击跳过；检查失败保留正式版，取消不重放，无代码成果正常显示。生效后查看版本，回退仅切换能力内容与引用，不能撤销历史或外部副作用。

### 模型与系统

提供方、Host 保存的独立副本、环境授权和实际调用分别说明。设备登录提供等待、取消、过期和回调模拟；保存 Key 后仍显示调用尚未验证。退出 Host 副本不声称提供方撤销，环境授权可继续存在。断线不等于停止任务；重新连接先读状态，不重发原任务。Desktop 维护作为原生流程说明，没有增加 Web 恢复覆盖入口。

所有示例都是内存中的脱敏数据；完整原文入口指的是完整的模拟记录，不冒充真实 Host 的原文或证据完整性。
