## 组件设计与实际职责

| 组件 | 原有问题 | 本轮处理与依据 |
| --- | --- | --- |
| Button / IconButton | 页面级覆盖导致控件尺寸与权重分散 | A 控件使用统一高度、圆角、边界与焦点；主操作、普通操作、危险操作有不同语义，图标按钮保留可访问名称 |
| Field / Input | 错误反馈与字段关系不够明确 | 统一输入边界、焦点和错误状态；关联 label、描述和错误信息，授权目标与范围错误就地显示 |
| Modal / Menu | 长授权内容与操作混在滚动区 | 为 Modal 增加可选独立 footer，窄窗口正文滚动而操作始终可达；保留 Radix 焦点、关闭和键盘行为 |
| Status / Notice | 工具返回与任务成功容易混淆 | 用明确文字表达已返回、失败、结论未知；信息提示与错误使用对应图标，颜色只补充语义 |
| TabBar / 列表选中态 | 选中关系分散在页面样式中 | 使用一致的选中、hover、focus 规则，修订列表提供按压状态，导航提供当前位置语义 |
| Markdown / Code / Diff / JSON | 阅读正文和操作文本缺少稳定层次 | 区分 UI、正文与等宽代码；保留既有高亮、Diff 与 JSON 渲染器，窄窗口代码保留可读字号和横向查看能力 |
| 动效 | 收起的开发记录可能残留运行标记 | 运行标记只存在于运行状态，终态卸载；减少动态效果设置下停止旋转、脉冲和骨架动画 |

A 的共同设计约束位于 `src/components/ui.css`，业务样式分别留在原有 conversation、memory、evolution 文件。修改公共组件时以 `.quiet` / `.quiet-surface` 限定 A 的外观；未建立 round5 或新产品布局。

## 三个业务场景

### 会话

工具活动从现有轨迹模拟数据读取，汇总读取、比较和查询，展开查看单次调用，再进入参数、返回与原有轨迹表。文件不存在保留 ENOENT；未知结果保留未知语义。自由输入不会补造工具记录。正文、引用、代码和底部输入沿用原有空间结构。

### 记忆

保留知识索引与对象详情，明确当前版本、历史修订只读、比较方向及修订来源。编辑始终以当前版本为基础；冲突保留草稿，经用户核对后保存新修订，历史内容不被覆盖。保存后显示具体修订编号。现有列表和 Diff 已能表达关系，因此没有增加修订关系图。

### 能力改进

建议首屏按对象、状态、问题、触发记录和操作组织。讨论完成前不能审阅授权。授权保留目标、已有 Skill 范围、新建范围、Host 当前用户权限、外部副作用及检查通过后自动生效的事实。开发、检查与终态使用真实模拟状态；失败、取消和无需修改均保留旧版本。
