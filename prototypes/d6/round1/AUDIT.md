## 产品与用户目标

个人通用 Agent 在 Host 设备执行工作。会话是工作的持续上下文；Memory 保存跨会话认识；Reflection 审查依据与局限；建议进入讨论后，由用户批准具体能力开发目标与范围。它不修改基础模型权重，也不是团队任务管理系统。

依据：`docs/01-产品定义/01-产品定位目标与用户.md:5-23`、`DECISIONS.md:21-45`、D2–D5 验收。

## 三条旅程与信息架构

1. 创建/切换会话 → 模型及引用 → 执行 → 结果 → 失败调用 → 输入输出 → 原始证据 → 返回任务。
2. 任务变化 → 当次 Memory → 当前认识 → 历史比较 → 来源 → 修正及理由 → 新修订。项目决定撤销与通用经验保留是不同状态。
3. 建议 → 独立讨论 → 用户明确目标与 Skill 范围 → 自主开发 → Agent 自测 → Host 检查 → 自动生效 → 普通使用 → 版本回退。失败保留旧版；取消与重启不重放；允许无代码成果。

常驻：工作定位、当前状态、主要目的入口。情境出现：运行、知识变化、待决定建议。按需展开：Tool 参数、历史修订、来源标识。聚焦表面：授权和完整原文。不得恢复已取消的独立全局日志入口。
