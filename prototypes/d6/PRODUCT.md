> 本轮授权（2026-10-23）：用户明确要求自主重设计 A 的记忆、技能与工具、反思记录、改进建议四模块，无需人工选择变体。该授权仅对这四模块覆盖下文历史“仅精修／不许可重新设计／未经用户选择不回写变体”及相关保留基线约束；B、会话、轨迹、设置与正式产品不在本轮范围。当前设计记录见 [src/workspace/DESIGN.md](src/workspace/DESIGN.md)；其余历史产品上下文保留。

## Platform

web

## Users

个人用户，通过 Web 或桌面客户端与自己的 Agent 长期协作。当前 D6 是供视觉与交互评审的 React/Vite 原型，不是正式 Web/Desktop。

## Product Purpose

Agent 是通用个人助手，现阶段以软件开发任务作为核心验证场景。用户主要通过 Session 完成工作；Agent 可以按需使用技能、工具和记忆，并在任务后整理有价值的发现、提出能力改进建议。

成功的体验：用户无需理解 Reflection、Evolution 等内部模块，也能找到要做的事、看懂结果和状态、明确自己是否需要操作。

## Positioning

支持用户控制的能力进化：Agent 可以反思并提出建议，用户先讨论后决定是否授权；未经批准不能自行进入能力修改和开发。执行轨迹与来源应可追溯。

## Operating Context

当前 D6-A「会话书桌」已经选定，现有导航、工作区布局、阅读区、Memory、技能与工具、能力建议与授权流程是保留基线。D6-B 是独立对照路线，不应修改。本轮以当前 A 的实际页面和组件为设计事实来源，不创建新的 Demo 或视觉主题。

D6 使用本地脱敏模拟数据；不会真正连接 Host、调用工具、授予权限或生效版本。正式 Web/Desktop/Host/数据库独立存在，不由这次试点修改。

## Capabilities and Constraints

- 现有功能：Session 对话及轨迹、记忆及版本、反思记录、Skill/Tool 管理、能力改进建议、讨论、授权、开发检查与回退的原型演示。
- 前端优先：成熟、易理解、可持续日常使用的界面；高质量的字体、布局、组件、动效和真实交互优先于测试界面的调试信息。
- 用户第一眼应知道：发生了什么、为什么与自己有关、现在能做什么。
- 不新增后端需求。没有实际证据，不编造任务成果、能力缺陷或改善价值；文案简短并不等于好理解。
- A 的现有设计已多轮评审，属于**精修**，不许可重新设计或整体替换组件。
- Impeccable Live 用于设计变体的探索和比较；未经用户选择，不接受、不回写变体。

## Product Principles

1. 工作优先，内部机制按需呈现。
2. 用户需要了解事实、操作后果与决策；不必先学习 Agent 架构。
3. 有真实业务意义的图形、动效和状态优于装饰。
4. 保留历史、来源、权限边界；易读不能以省略关键事实为代价。
5. 在已有 A 上增量完善，验证真实使用体验而不只验证构建或截图。
