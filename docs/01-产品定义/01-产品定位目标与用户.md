# 产品定位、目标与用户

## 产品定位

Self-Evolving Agent（自进化智能体）是面向个人用户的通用 Agent。它在完成任务的同时，能够跨会话积累认识，审查自身行为、工具与知识的局限，并在用户授权下改进已有能力或创造全新能力。

首个验证场景为软件开发。产品不局限于 Coding；文件管理、信息研究、办公自动化等是可以继续扩展的任务领域，不因此为每个领域重新建设一套 Agent。

## 目标用户与使用关系

- 一个 Pi Agent 实例服务一个用户，允许同一用户从多个设备访问。
- 面向希望持续使用、维护和扩展个人 Agent 能力的用户。
- Web 与 Windows/macOS 桌面端提供交互；支持本地及远程访问，远程访问需要身份验证。
- 所有 Tool 在 Pi 实例所在设备执行，使用该设备的文件、依赖和运行环境。

## 产品目标

1. 基于真实执行经历，认识自身的判断依据、行为方式和能力边界。
2. 将有价值的经验、怀疑与认识长期保存，并能根据新证据修正。
3. 从已有知识举一反三，自主提出具有合理价值的新能力构想。
4. 获得授权后完成实际验证、开发和测试，使新能力能在后续任务中使用。

“越用越聪明”指系统的知识、实践经验、能力选择和工具能力持续改善，不指修改基础 LLM 的模型权重。
