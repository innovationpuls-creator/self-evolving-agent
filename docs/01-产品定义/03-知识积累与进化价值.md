# 知识积累与进化价值

## 三类成果

| 层次 | 目的 | 结果要求 |
|---|---|---|
| 认识反思 | 审查判断依据、行为和能力局限 | 留下可追溯记录，不强制发现问题 |
| 知识积累 | 保留有持续价值的认识、经验、怀疑 | 不要求每次反思都更新知识 |
| 能力进化 | 改进方法、工具或创造新能力 | 有合理价值才提出，授权后再实施 |

三者相互关联但不强制绑定。保存知识不必修改 Tool，提出新能力不必先发现错误，开发活动也可以只形成认识成果而不产生代码。

## 价值判断

同时追求实际工作能力改善与探索性能力增长。价值可表现为：

- 减少有证据支持的不必要调用、上下文消耗和耗时。
- 提高可靠性，明确能力在什么条件下有效。
- 获得此前不具备的任务处理能力。
- 认识并纠正自身的判断、记忆使用或反思盲区。
- 将已有知识迁移、组合成有潜在用途的新能力。

不以 Tool 数量、建议数量、怀疑数量或反思文本长度直接衡量进化。不为这些价值预设固定权重，也不要求每次进化立刻产生收益。

## 长期积累

每次反思产生必要记录，长期知识择优保存；普通、重复或失效的认识可以整理、合并或淘汰。原始执行证据另行保留，不能用一段总结替代。

怀疑可以在长期记忆中独立存在，等待未来证据支持或推翻；不能因为被保存就视为事实。
