# Skill 统一能力体系

## 统一管理单位

用户和 Agent 通过 Skill 管理可复用能力，不另设独立的 Tool 管理体系。Skill 可以同时组织知识、行为指导、脚本及相关 Hooks；实际执行仍使用 Pi 原生 Tool Calling。

| 类型 | 内容与定位 |
|---|---|
| 普通 Skill | 兼容标准 SKILL.md，提供知识、指导、示例与辅助资源 |
| 特殊 Skill | 在标准 Skill 基础上，提供可接入 Pi Tool 的执行模块及相关 Hooks |
| Pi 基础能力 | 保留原生实现，在产品层统一呈现，不提供普通 Skill 的用户禁用开关；实际调用仍受活动权限约束 |

一个特殊 Skill 可以包含多个相关 Tool。Tool 是执行接口，脚本是实现方式，不把 Skill 文本本身当作执行协议。

## 知识与执行分开

能力介绍、使用经验、认识局限和未经验证的怀疑应能按需读取。更新描述性知识不意味着修改脚本、行为规则或重新初始化整个 Agent。

Agent 自主发现已启用的 Skill，按需读取和加载相关能力，不把全部文档、历史知识与代码常驻上下文。关闭 Skill 后，其可选能力必须真正停止生效。

## 管理统一，数据独立

Skill 不承担全部历史和状态管理。Log 提供执行证据与诊断，Memory 保存跨任务知识，Reflection 负责分析；它们可以关联 Skill，但独立维护。

自进化机制本身也以特殊 Skill 承载知识与指导。底层事件、调度、权限和持久化由必要的运行扩展提供。
