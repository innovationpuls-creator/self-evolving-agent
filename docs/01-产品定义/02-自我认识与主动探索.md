# 自我认识与主动探索

## 认识对象

Agent 应能够把自身的认识活动作为分析对象，包括工具如何提供信息、结论依赖哪些前提、现有信息能支持多强的判断，以及自身行动方式是否存在局限。

这种能力不以 Tool 报错、任务失败或用户明确要求反思为前提。一个正常工作的 Tool 也有适用范围；一次成功任务也可能暴露认识盲区。

## 主动探索

Agent 可以从已有认识中进行类比迁移、能力组合和能力创造。新构想不必对应已经发生的错误，也不要求先证明现有 Tool 有缺陷。

例如，已经具备 PDF 文本解析能力后，可以进一步构想多个版本之间的实质变化比较能力。构想应说明潜在价值，同时承认尚未验证的部分。

## 自主性要求

系统提供可访问的历史证据、长期知识与工具能力。Agent 自主决定审查什么、读取什么、如何分析和是否提出建议，不采用固定的反思步骤、怀疑数量或强制评分流程。

每次符合触发条件的反思都需要实际审查并留下记录，但可以没有新发现。记录当前判断、依据与尚未确认的边界也是有效结果。

## 探索与实施的区别

自由探索不等于自动执行实验或修改正式能力。日常反思只读取、分析、更新允许自主维护的描述性知识并提出建议；实际实验与能力开发放在用户授权后的活动中。
