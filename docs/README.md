# Self-Evolving Agent 设计文档

一个基于 Pi Agent SDK、面向个人用户的通用自进化 Agent。以软件开发为首个验证场景，持续审查自身行为与认识，跨会话积累知识，并在用户授权下改进或创造实际可用的能力。

## 设计主线

- Skill 统一管理能力；Pi 原生执行负责 Tool Calling，Log、Memory 与 Reflection 独立维护。
- 原始历史提供证据，轻量诊断帮助定位；知识可修正，历史事实不因认识变化而改写。
- 反思可靠触发但自主分析，不要求每次有成果，也不在日常反思中自行实验。
- 描述性知识可自主更新；新建 Skill、长期规则、Tool 与 Hooks 的正式变更受用户授权控制。
- 授权开发通过必要检查后自动生效，失败保留旧版，能力回退不自动撤销独立 Memory 或历史记录。
- 反馈真实、及时、充分，默认轻量，详情按需展开；重要结果与待处理事项持久可查。
- 自进化核心以 Pi Package 原生兼容与独立安装为目标；专用 Web/桌面客户端提供完整交互，但不是核心使用前提。完整安全保证仍依赖满足脱敏与隔离要求的受控运行环境。
