# EQ-03：数据可靠性与故障恢复验收

## 权威来源

Pi Session、业务数据库与 Skill 文件分别保存，恢复时各有依据。SQLite 事务不自动覆盖外部快照或版本文件，不为此新增数据库、分布式事务或另一套历史系统。

| 数据 | 恢复依据 |
|---|---|
| 对话与执行历史 | 最后一个完整有效的 Pi Session 加密检查点 |
| Memory、Reflection、建议和后台任务等业务状态 | SQLite 已成功提交的事务 |
| 正式 Tool、Hooks、长期行为规则及其资源 | 不可变能力版本文件与 SQLite 正式版本引用 |
| 描述性 Skill Knowledge | 独立保留的知识修订历史与必要的历史关联，不逐次发布 Skill Version |

知识修订不能改变旧能力版本的含义。恢复历史能力或执行记录时，仍应区分当时关联的知识与后续修正；能力回退不自动撤销独立 Memory 或改写 Log。

## Session 快照提交

提交顺序为：生成包含匹配 Session 条目与 `leafId` 的完整加密快照，安全写入并确认完整，再更新 SQLite 中的有效快照引用。

新快照完整保存前，不得成为唯一恢复入口。文件写入使用临时文件、适当同步与原子替换，保留上一有效检查点。恢复时验证完整性及加密认证，再恢复原生 Session 和对应 `leafId`。

最新快照损坏时，可尝试上一有效检查点，并明确报告可能丢失的进度。密钥丢失或认证失败时报告无法解密，不绕过保护或退回明文 JSONL。

检查点间的历史损失边界必须明确，不承诺任意时刻断电都保留最后一个 Token。快照频率与性能处理见 EQ-05，不能为减少写入而无声丢失大量已完成工作。

## SQLite 与备份

业务数据库默认采用 **WAL + `synchronous=FULL`**，尤其保护 Memory、授权和正式版本发布等重要提交。原对话区分了 WAL 下 NORMAL 的一致性与 FULL 更强的断电提交持久性；不能把启用 WAL 本身当作完整可靠性证明。

- 相关业务状态在事务中共同提交。
- 迁移可识别版本，失败可恢复，不继续使用不完整结构。
- 使用 SQLite 支持的一致性备份，运行时不能只复制主文件而忽略 WAL。
- SQLite 与 Session 加密快照的备份应匹配，避免恢复出无法对应的时间点。

正式验收同时检查文件、引用与业务状态的一致性，不将数据库自身的事务保证扩展为所有存储或外部操作的原子性。

## Skill 与后台任务恢复

正式能力先准备并验证新版本文件，再更新 SQLite 正式引用；Host 按引用加载。旧版确认不再使用前不得删除，初始化失败恢复 Last Good 并保留原因。知识独立修订规则不因文件版本恢复而改变。

SQLite 保存任务状态，但无法替外部 Tool 保证副作用恰好一次。恢复必须区分尚未执行与可能已经执行但结果未知的任务；不能把所有中断任务直接改回等待执行。

对话恢复到检查点，不等于所有活动自动继续。涉及文件修改、外部服务等真实副作用时，应检查实际结果后再确定安全的恢复方式。

## Memory 的来源与当前适用性

回档不自动删除外部 Memory。历史来源用于追溯，当前适用性还需识别明确撤销、替代及适用背景，通用经验与项目决定分别判断。

该要求也覆盖跨会话 Project Memory：Session A 回档撤销决定后，Session B 读取同一项目知识时，不能仅凭自己的 `getBranch()` 判断 A 的决定仍有效。共享项目决定应具有可追溯的当前适用状态，不能将来源 Entry 或历史分支关系当作充分依据。

已撤销决定不得重新成为当前要求，历史事实和仍有效的经验可以保留。不为此重建 Pi 分支系统，也不能抹去已发送给模型的上下文。

## 故障场景与验收

| 故障 | 正确行为 |
|---|---|
| 快照写入一半时崩溃 | 使用旧有效快照，不加载不完整文件 |
| SQLite 提交时进程退出 | 恢复到数据库认可的完整事务状态 |
| 快照保存后、引用更新前崩溃 | 仍按旧有效引用恢复，新文件经恢复核对后处理 |
| Skill V2 已暂存、未发布 | 继续使用 V1 |
| V2 发布后初始化失败 | 恢复 Last Good，保留错误信息 |
| Tool 已产生副作用、完成记录未提交 | 标记中断，检查结果，不盲目重放 |
| Memory 更新后会话回档 | 保留历史，重新判断适用性，跨会话检索也不沿用已撤销决定 |
| 密钥丢失或快照认证失败 | 报告无法解密，不降低安全要求 |

通过模拟数据的故障注入与恢复测试证明：已确认提交的数据不无声丢失；不同存储的正式状态有可解释依据；未知副作用可查询、检查和处理；数据损坏不触发权限、加密或版本验证降级。正常关闭应用不足以完成验收。
