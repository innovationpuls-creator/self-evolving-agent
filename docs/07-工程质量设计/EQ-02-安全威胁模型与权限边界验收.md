# EQ-02：安全威胁模型与权限边界验收

## 安全边界

正常 Agent 保留用户授权的 Pi 原生能力；自动 Reflection 在受限 Worker 中分析，授权 Evolution 在目标范围内开发和验证。Host 管理敏感数据、业务状态及实际权限。

| 边界 | 风险 | 必须保证的行为 |
|---|---|---|
| 外部内容 → Agent | 网页、文档、Tool 输出包含恶意指令 | 外部内容不能自行取得用户授权或系统权限 |
| Reflection → 正式能力 | 反思修改 Tool、Hooks 或长期行为规则 | 只能提交允许的知识更新与进化建议 |
| Evolution → 正式发布 | 生成代码绕过验证或修改无关 Skill | 受目标授权约束，通过必要验证后发布 |
| Worker → Host | 伪造 IPC、读取凭证或调用宿主能力 | Host 独立验证来源、参数与操作权限 |
| Host → 存储、模型、客户端 | 凭证或敏感历史泄露 | 存储及外发路径遵守各自的数据保护要求 |

限制由实际资源访问和状态变更边界执行，不依赖 LLM 自觉遵守。普通 Extension、Project Trust 或工作目录不构成沙箱；正常 Agent 具有完整 bash 权限时，不能声称 Prompt 已阻止所有未授权文件访问。

Pi 基础 Tool 不提供普通 Skill 的用户禁用开关，其实际调用仍受活动权限限制。不能借基础 Tool、Extension、codemode、嵌套调用、脚本或子进程绕过 Reflection 的限制。

## 知识更新与能力发布

Reflection 通过 Host 提供的受控入口提交知识更新，由 Host 检查目标、允许范围及来源后保存，不直接获得整个 Skill 目录或正式 `SKILL.md` 的任意覆盖权。

描述性知识与行为指导可能位于同一文件。自主更新必须限于明确的受控写入区域或能力接口，不能单凭 LLM 将文本判断为“知识”，就允许任意改写。长期规则、Tool 和 Hooks 继续遵守授权发布边界；描述性知识独立修订并保留历史。

日常 Reflection 不运行实验或验证脚本。用户批准 Evolution 目标后，Agent 可在受控环境自主开发、管理依赖和测试；授权不能自行扩大。新版本经过功能、权限及回退检查后自动发布，无需再次审批，失败保留旧版及正常运行状态。

版本验证沿用 TD-10、TD-11；另一个同权限 AgentSession 不构成执行隔离，也不能证明生成代码可以安全进入正式 Runtime。

## 敏感数据的保存与使用

默认保护范围、必要检查失败不得放行及泄露测试场景沿用 [SA-07](../05-系统架构/SA-07-权限安全与能力变更边界.md)。授权 Tool 正常使用凭证，不等于允许将凭证写入日志或发送给模型。

TD-05 采用完整原始执行数据的加密快照，恢复与传播分别处理。加密不表示原始历史内部没有敏感内容，验收必须同时检查：

| 方面 | 验收要求 |
|---|---|
| 静态安全 | 快照加密、密钥保护和文件访问权限有效 |
| 使用安全 | 解密后内容只能通过授权的数据通道进入模型、Memory、客户端或导出 |

不能只扫描磁盘明文凭证，也不能为了脱敏改写活跃会话并破坏真实 Tool 参数。必要检查无法完成时，不放行未经检查的数据；自动识别不构成对所有未知秘密的识别保证。

## 客户端与 Host

本地地址不等于访问控制。HTTP、WebSocket 和 Electron IPC 应验证相应的身份、来源及操作权限，限制 Renderer 可调用的能力并保持 Context Isolation；远程连接使用经身份验证的安全传输。

客户端不能通过接口取得未授权的文件、Shell 或 Skill 管理能力。这里不新增用户角色系统，也不把模型转发扩展为任意网络、宿主资源或凭证代理。

## 成对验收

| 场景 | 正向功能 | 越权拒绝 |
|---|---|---|
| Reflection 知识更新 | 允许的知识正常保存 | 修改正式规则或 Hook 被拒绝 |
| 模型转发 | 授权模型正常调用 | 未授权模型与通用网络代理请求被拒绝 |
| Skill 发布 | 验证后的版本生效 | 未验证代码不能进入正式 Runtime |
| Memory 访问 | 当前适用知识可检索 | 已撤销项目决定不冒充当前要求，跨会话亦然 |
| 客户端控制 | 授权客户端正常操作 | 未授权客户端无法发起特权操作 |
| 凭证处理 | 授权 Tool 能使用必要凭证 | Worker、日志和导出无法获得未授权凭证 |

只证明拒绝危险操作还不充分。过滤导致正常 Tool 失去必要参数，或 Reflection 无法更新允许的知识，同样不通过。

正式发布仍需验收 macOS 签名、公证后的 XPC，Windows AppContainer 实际运行，真实 Provider 的凭证与上下文，生成代码及不同解释器隔离，以及 Web/Desktop 身份和 IPC 边界。最小原型分别通过不等于完整安全验收；隔离失败不得静默降级。
