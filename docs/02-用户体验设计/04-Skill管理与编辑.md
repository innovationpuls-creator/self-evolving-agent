# Skill 管理与编辑

## 统一入口，渐进展示

用户通过同一入口管理普通 Skill 和特殊 Skill，根据内容展示必要信息，不要求用户先理解 Tool 注册机制。

| 类型 | 默认信息与按需展开内容 |
|---|---|
| 普通 Skill | 用途、知识文档、启用状态与编辑入口 |
| 特殊 Skill | 在普通内容基础上，展开 Tool、脚本、依赖、认识与怀疑、使用历史和版本 |
| Pi 基础能力 | 统一呈现必要能力，不提供普通 Skill 的用户禁用开关；实际执行仍受活动权限约束 |

默认突出 Skill 的用途和能力，代码、日志、历史与诊断按需展开。

## 两种编辑方式

**直接编辑**：用户可以在 Web、桌面端查看和修改 Markdown、脚本及相关文件。

**AI 协助编辑**：用户用自然语言提出需求，Agent 理解现状并讨论目标，在授权范围内修改与测试。

两种方式操作同一份 Skill，不产生两套独立资源。用户写下的描述性知识也可以被 Agent 根据新证据修正；长期行为规则和执行内容仍受正式变更权限约束。

## 启停与按需使用

已启用 Skill 的发现、读取和加载由 Agent 自主决定，用户无需为每次使用重复操作。禁用后，其可选 Tool 和 Hooks 必须停止生效，而非仅从前端或模型列表隐藏。

保存、检查与生效按修改类型处理：描述性知识可以直接更新，可执行内容需必要检查；具体失败和回退体验见关联文档。
