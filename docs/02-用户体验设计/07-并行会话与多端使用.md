# 并行会话与多端使用

## 日常任务与能力进化并行

正常聊天、后台反思和能力进化可独立运行，用户可随时切换查看，不必等待开发结束再继续普通任务。

不同会话共享已正式生效的 Skill 和适用的 Memory；未检查通过的代码不能影响正式能力。用户切换会话不意味着中止原任务。

同一会话的新输入遵循 Pi 原生消息调度，不通过多个并发请求驱动同一 AgentSession。具体 SDK 接口行为仍需技术验证。

## 本地与远程

- Web、Windows、macOS 客户端提供一致的核心能力与管理体验。
- 一个实例服务一个用户，支持该用户多设备连接。
- 本地使用与远程连接都由 Pi 主机执行 Tool，使用主机的路径、系统与依赖。
- 远程访问需要身份验证，不引入多租户或团队角色系统。
- 多客户端访问同一会话时，状态应一致，避免重复提交操作。

## 断开、关闭与恢复

| 用户或运行事件 | 预期结果 |
|---|---|
| 关闭页面或退出客户端 | 主机仍运行时，已提交任务继续 |
| 网络中断 | 主机继续执行，重连恢复状态与必要历史 |
| 主动切换或结束会话 | 不同于关闭窗口；待反思内容可按规则提前触发 |
| Pi 进程退出 | 恢复持久化会话和任务记录，识别完成与中断 |

恢复不能被理解为可以安全续跑任意 Tool。不能确认某次有副作用操作是否完成时，不盲目重放；向用户展示真实的中断状态。
