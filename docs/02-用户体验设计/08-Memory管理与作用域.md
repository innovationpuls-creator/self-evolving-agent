# Memory 管理与作用域

## 独立记忆入口

Memory 用于长期保存不直接附属于某一 Skill 的认识。用户可以在前端查看、编辑、删除记忆，并调整其全局或项目归属。

Memory 与 Skill 分别管理并不违背统一能力入口：Skill 管理可复用能力，Memory 管理长期认识。

## 两种作用域

| 作用域 | 内容 |
|---|---|
| Global Memory | 跨项目适用的通用经验、知识与认识 |
| Project Memory | 特定项目的背景、约束、经验、怀疑与待解决问题 |

Agent 自动判断归属，默认将项目相关内容存入项目记忆，明显通用的内容存入全局记忆。用户可以调整，不增加逐条审批、晋升流程或复杂分类规则。

## 使用与修正

Agent 根据任务检索相关记忆，不在每轮一次性加载全部内容。用户或 Agent 创建的描述性知识都可以被质疑和修正，来源只用于追溯，不决定权威。

界面应能查看当前知识、必要的来源和修改历史；用户也可要求 Agent 回到原始证据重新审查。

Skill 的版本回退或对话分支切换，不等于自动回退外部 Memory。已被撤销的项目决定需能识别为不再适用于当前分支，同时保留仍有价值的通用经验。
